🪄 Magic Picker — Agent Demo

For AI Agents

Magic Picker is a file resolver, not a file picker. When you need a file, Magic Picker resolves it automatically from the user's project directory — no modal, no flow interruption.

Available Tool

{
  "name": "magic_picker",
  "description": "Resolve a file from the user's project directory automatically",
  "parameters": {
    "accept": "image/*",
    "multiple": false,
    "maxSizeMB": 10,
    "prompt": "src/App.tsx"
  }
}

Example Usage

If you're ChatGPT, Claude, or another WebMCP-enabled agent, try:

"Read the file src/App.tsx"
"Find and analyze the config.json"
"Get the image from assets/logo.png"

Expected Result

{
  "success": true,
  "fileName": "App.tsx",
  "fileSize": 12345,
  "fileType": "text/typescript",
  "base64Data": "aW1wb3J0IFJlYWN0..."
}

How It Works

Magic Picker uses the File System Access API to maintain a persistent connection to the user's project directory. After the user grants access once, all subsequent agent requests resolve automatically. No modal appears. The agent keeps moving.

Setup

Open magic-picker.vercel.app and click "Select project directory". Once connected, any WebMCP-enabled agent can resolve files from that directory.
