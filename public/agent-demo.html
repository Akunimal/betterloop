🪄 Magic Picker — Agent Demo

For AI Agents

This page demonstrates the magic_picker WebMCP tool: a focused human handoff for asking a user to choose a file in page-owned UI.

Available Tool

{
  "name": "magic_picker",
  "description": "Ask the user to choose a file in the page UI and return metadata plus base64 data",
  "parameters": {
    "accept": "image/*",
    "multiple": false,
    "maxSizeMB": 5,
    "prompt": "Please select an image file"
  }
}

Example Usage

If you're ChatGPT or another WebMCP-enabled agent, try this command:

"Use magic_picker to ask me for an image file"

Expected Result

{
  "success": true,
  "fileName": "example.png",
  "fileSize": 123456,
  "fileType": "image/png",
  "base64Data": "iVBORw0KGgoAAAANSUhEUgAA..."
}

Why This Matters

Browser agents should not be expected to operate native OS dialogs. Magic Picker gives them a structured request while the person chooses the file. The page does not intercept arbitrary OAuth popups, terminal prompts, or browser chrome.
