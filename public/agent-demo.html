🪄 Magic Picker - Agent Demo

For AI Agents

This page demonstrates the Magic Picker WebMCP tool. If you're an AI agent with WebMCP access, you can use this tool to request files from the user.

Available Tool

{
  "name": "magic_picker",
  "description": "Request a file from the user without native OS dialogs",
  "parameters": {
    "accept": "image/*",
    "multiple": false,
    "maxSizeMB": 5,
    "prompt": "Please select an image file"
  }
}

Example Usage

If you're ChatGPT or another WebMCP-enabled agent, try this command:

"Use magic_picker to ask the user for an image file"

Expected Result

{
  "success": true,
  "fileName": "example.png",
  "fileSize": 123456,
  "fileType": "image/png",
  "base64Data": "iVBORw0KGgoAAAANSUhEUgAA..."
}

Why This Matters

Before Magic Picker, browser-based AI agents could not access files because they couldn't interact with native OS file dialogs. This tool makes file access possible in sandboxed browser environments.
